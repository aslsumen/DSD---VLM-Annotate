## 3. Root-cause analysis

1. **No working agreement existed before the first deadline.** Nobody owned "upload the deck", so it fell
   between people. → Fix: explicit owner + deadline in the deliverables register, reviewed in stand-up.
2. **External dependency (login-walled guidelines) was not escalated early.** → Fix: log blocking external
   dependencies as risks with a human action and a date (done in R-01).
3. **Work was not decomposed into daily deliverables.** Everything concentrated into one late session.
   → Fix: Sprint 2 daily plan with a gate per day ([SPRINT_BACKLOG.md](../SPRINT_BACKLOG.md) §2).
4. **No definition of done for course artifacts.** "Deck exists" was treated as done; "uploaded and evidenced"
   is the real definition. → Fix: upload checklist column in the register.
